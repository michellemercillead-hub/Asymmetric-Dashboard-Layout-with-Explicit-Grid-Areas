# Dashboard Layout with Explicit Grid Areas

This project is a simple admin dashboard built with HTML and CSS using CSS Grid with explicit grid areas.

## Overview

The page includes:
- a large chart card spanning multiple columns and rows
- compact metric cards aligned and centered with compound grid alignment properties
- a tall activity feed card on the right side
- a wide status panel across the bottom
- responsive behavior for smaller screens

## Files

- `index.html` – dashboard markup
- `styles.css` – dashboard styling and grid layout

## Prompt used

> "I need to write a modern stylesheet for this admin dashboard HTML [paste HTML]. The `.dashboard-grid` should use CSS Grid. Establish an explicit 4-column layout on desktop using grid-template-areas. Assign the large chart card to span multiple columns and rows, the activity feed to span vertically down the right side, and the status card to stretch wide across the bottom. Use compound alignment properties (align-content, justify-items, align-items) inside the metric cards to center the values. Provide clean CSS and explain the difference between our explicit tracks and any implicit tracks that form if content overflows our area definitions." I also need all code to pass lighthouse verification

## Notes

This project is designed to be simple, accessible, and valid HTML/CSS while following the requested layout patterns for clear dashboard composition.
